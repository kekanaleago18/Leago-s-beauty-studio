## 1. Project Overview

Leago Beauty Studio is a boutique spa website for a business with two studios in Midrand (Noordwyk and Waterfall). The site offers facials, massages, nail care and waxing. Its purpose is to inform clients about the services, show prices and memberships, and let them make enquiries and contact the studio.

**Target audience:** Clients who want a quick treatment on a lunch break, and clients booking a full relaxation package for a special occasion.

## 2. Pages

- index.html: Home page with the hero section, introduction and calls to action.
- about.html: History, mission and vision, target audience and team.
- services.html: Treatments by category, with an accordion and a photo lightbox.
- pricing.html: Prices loaded by JavaScript, with search, filter and sort.
- membership.html: Silver, Gold and Platinum membership tiers.
- enquiry.html: Enquiry form with validation and a cost and availability response.
- contact.html: Studio details, interactive map and a contact form.

## 3. Technologies Used

- HTML5 for structure
- CSS3 for styling, transitions and animations
- JavaScript for interactivity, dynamic content and form validation

- Git and GitHub for version control; GitHub Pages for hosting

## 5. Part 3 Features

**JavaScript functionality**
- Accordion on the Services page to show and hide treatment lists.
- Gallery lightbox on the Services page: clicking a photo opens it larger.
- Dynamic pricing on the Pricing page, loaded from a JavaScript array, with search, category filter and sorting.
- Interactive map on the Contact page with a marker and popup for each studio.
- Animations and transitions: hero fade-in, scroll fade-in on the About page, hover effects on membership tiers and photos.

**Forms**
- Enquiry form: validates name, email, phone (10 digits starting with 0), service, date (not in the past) and time (within opening hours). Shows an error message under each invalid field. When valid, it shows an estimated cost and availability.
- Contact form: validates name, email, phone, message type and message length. When valid, it builds an email addressed to the studio.

## 6. SEO

**On-page**
- A unique title tag and meta description on every page.
- A meta keywords tag on every page.
- One H1 per page, with H2 and H3 headings below it.
- Descriptive image file names and alt text.
- Clean URLs and internal links between all pages.
- A mobile-friendly responsive design.

**Off-page (planned)**
- Backlinks from local business directories.
- Promotion on Instagram and Facebook.
- A Google Business Profile for both studios for local SEO.

**Additional**
- robots.txt tells search engine crawlers which pages they may index.
- sitemap.xml lists all pages so search engines understand the site structure.
- Page speed: images resized and compressed, and scripts loaded at the end of each page.
- Security: the site is served over HTTPS by GitHub Pages, and user input is validated before it is used.
